# Titanic Passenger Survival Prediction Using PySpark

## Project Overview

This independent machine-learning project explores the prediction of Titanic passenger survival using Python and Apache Spark (PySpark). It demonstrates a machine-learning workflow using passenger data, feature engineering, logistic regression, and model evaluation.

## Objectives

- Prepare passenger data for machine-learning analysis.
- Build a machine-learning pipeline using Apache Spark.
- Apply logistic regression to predict passenger survival.
- Evaluate model predictions using classification evaluation methods.

## Tools and Technologies

- Python
- Apache Spark (PySpark)
- Spark ML Pipeline
- Tokenizer
- HashingTF
- Logistic Regression
- MulticlassClassificationEvaluator
- MulticlassMetrics
- BinaryClassificationMetrics

## Dataset

The project uses Titanic passenger data containing fields such as passenger class, age, sex, survival outcome, and passenger identifiers. The notebook references a dataset hosted by the American Statistical Association.

## Methodology

The notebook builds a Spark ML pipeline incorporating text processing, feature hashing, and logistic regression. The data is divided into training and testing subsets, and the trained model is used to generate predictions for evaluation.

## Project Scope and Limitations

This repository documents an independent analytical project. Results depend on the dataset, preprocessing choices, and model configuration in the notebook. The project is presented for educational and portfolio purposes; it is not represented as a production deployment or a peer-reviewed publication.

## Reproducibility and Data Source

The original notebook was exported to HTML for public portfolio presentation. Credentials and sensitive configuration details were removed from the published copy.

Dataset reference: [American Statistical Association — Titanic Dataset](https://ww2.amstat.org/publications/jse/v3n3/datasets.dawson.html)
